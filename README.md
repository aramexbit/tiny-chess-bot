A 4KB Python chess engine for make.fun's tiny-chess-01 bounty. Original 0x88 alpha-beta engine with transposition table, null-move pruning, killer and history move ordering, and quiescence search. Elo 1451 on practice trial 0.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
